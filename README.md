# Портфолио Анастасии Кобзаревой

Личный сайт UX/UI-дизайнера: выбранные работы, подробные кейсы, опыт и контакты.

## Страницы

- `index.html` — главная.
- `university.html` — анонимизированный интерфейсный кейс образовательных организаций.
- `talentmind.html` — основной и международный сайты TalentMind.
- `marketing.html` — Вебпрактик.Маркетинг, дизайн и реализация с ИИ.
- `webpractik-ai.html` — сайт Вебпрактик AI.
- `photoschool.html` — фотошкола 1.61: сайт под ключ, путь к заявке и SEO.

## Локальный просмотр

Откройте `index.html` в браузере. Сборка и установка зависимостей не требуются.

HTML, CSS и JavaScript без фреймворков. Локальные изображения, шрифты и PDF находятся в `assets/`. Лицензии Bounded и Onest сохранены рядом со шрифтами. Адаптивная вёрстка, поддержка reduced motion, просмотр макетов в диалоге, рабочие ссылки контактов и скачивание PDF.

Визуальная версия: тёмная сцена из реальных работ, асимметричная сетка проектов, электрический синий и лаймовый акцент на тёплой светлой основе. Есть появление работ при прокрутке, наведение и клавиатурный фокус на обложках, индикатор прочтения. Просмотр макетов поддерживает масштабирование, прокрутку, вписывание и закрытие по Escape с возвратом фокуса.

## Проверенная версия

Базовые пять страниц проверены в браузере на ширинах 1280 и 390 px; главная и длинные заголовки дополнительно на 320 px. После добавления фотошколы повторно проверены главная и новый кейс на широком и мобильном экранах, 116 локальных целей ссылок/файлов. Для изображений заданы исходные размеры, чтобы резервировать место до загрузки. Это не полная проверка всех устройств и браузеров.
